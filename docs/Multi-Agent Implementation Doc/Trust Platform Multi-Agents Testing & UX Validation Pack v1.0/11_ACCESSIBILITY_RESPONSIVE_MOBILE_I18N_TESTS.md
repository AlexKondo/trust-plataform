# 11 — Accessibility, Responsive, Mobile & i18n Tests

Validate keyboard navigation, visible focus, semantic labels, screen-reader names/roles, logical reading order, contrast, zoom/reflow, touch targets, reduced motion, form errors and status announcements. Test representative viewport widths and mobile portrait/landscape; no clipped monetary values or hidden critical CTA.

Test locale switching, text expansion, date/time/number/currency formatting, translated validation/errors/notifications, and no hard-coded user-facing English when a localized string should be used. Preserve IDs/enums internally while localizing presentation.
