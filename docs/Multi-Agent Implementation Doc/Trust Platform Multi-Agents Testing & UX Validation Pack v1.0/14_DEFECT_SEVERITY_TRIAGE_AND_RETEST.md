# 14 — Defect Severity, Triage & Retest

Sev-1: financial loss/release error, critical security/privacy breach, systemic corruption, impossible core journey. Release blocked.
Sev-2: major feature unusable, authorization boundary failure without proven exploit, serious UX misunderstanding on money/confirmation, high-impact incorrect AI action/recommendation. Release blocked.
Sev-3: material but workaround exists. Must be risk-accepted or fixed.
Sev-4: cosmetic/minor friction. Can be deferred with owner.

Defect record: ID, requirement/test, environment/build, persona, preconditions, exact steps, expected/actual, screenshots/log/correlation ID, severity/rationale, suspected component, owner, fix version, retest result, regression scope.
