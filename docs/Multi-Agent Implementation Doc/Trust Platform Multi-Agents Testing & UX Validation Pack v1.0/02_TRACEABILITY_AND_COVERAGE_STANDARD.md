# 02 — Requirements-to-Test Traceability & Coverage Standard

Create `RTTM.csv` with: Requirement ID, source document, business capability, risk tier, test IDs, automation status, last result, defect IDs, evidence URI, owner.

Coverage rules: 100% of approved MVP requirements traced; 100% of critical state transitions; 100% of financial invariants; 100% of role/ownership authorization boundaries; 100% of irreversible actions; all primary Member and Partner journeys; all supported locales at smoke level and primary locale at full level. Code coverage is supporting evidence, never a substitute for requirements coverage.
